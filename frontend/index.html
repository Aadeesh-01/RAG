Ask a Python codebase. Get answers that cite the code.

coderag finds the functions that match your question, follows the calls between them, and answers with a citation for every claim. Click a citation and you are at the exact lines.

Try the sample repository

Python only. Public GitHub repositories. Code is read, never run.

How an answer is made

  1. It finds the code

    Every function, method and class is indexed on its own. Your question is matched against them, not against whole files.

  2. It follows the calls

    Calls are resolved from imports and classes, so the answer also sees what the matching code calls, and what calls it.

  3. It cites every claim

    The model answers from those sources only and cites them as S1, S2. Each citation opens the file at the lines it came from; the call graph shows the path that found it.
