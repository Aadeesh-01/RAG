# coderag

Ask questions about a codebase and get answers that cite the code they come from, with the call
graph that connects it. Pick a demo repository or sign in with GitHub to index your own.

This Space runs the Docker image built from the repository's [Dockerfile](Dockerfile). Its
settings are the Space's secrets and variables; see the "Deploy" section of the project README.
